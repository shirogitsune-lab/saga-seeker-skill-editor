最初の3手順

アプリを起動し、「HTMLファイルを開く」または「新規作成」を選びます。
タブを切り替えて編集します。画面下の「変更」件数で未保存の変更を確認できます。
「別名で保存」します。読み込んだ元のHTMLへ自動で上書きしません。

HTMLを開く・新規作成

既存のキャラクターシートを開く

  1. 「HTMLファイルを開く」を押します。
  2. ゲームから出力したキャラクターシートのHTMLを選びます。
  3. キャラクター名とスキル欄の概要を確認します。

ファイル選択ダイアログはWindows環境によって見た目が変わるため、ガイド画像には含めていません。

新規作成

「新規作成」は空のキャラクターシートを作ります。名前、プロフィール、ステータス、スキル、性格キーワード、思い出を入力してから別名で保存してください。

各項目を編集する

「基本情報」「ステータス」「スキル」「性格キーワード」「思い出」のタブを切り替えます。

基本情報とプロフィール

キャラクター名は1行で入力します。プロフィール7項目は複数行を使えます。長い項目は見出しを押して展開・折り畳みできます。

キャラクター画像

シートを読み込むと、埋め込まれた画像が基本情報タブへ自動表示されます。表示に失敗した場合は他の項目を引き続き編集でき、「プレビューを再読込」で安全検査を通した再表示を試せます。画像欄が読み取り専用のときも既存画像は表示されますが、差し替えはできません。

プロフィールを比較する

「プロフィール比較を表示」を押すと、2項目と性格キーワードを横に並べられます。別ウィンドウ表示も選べます。

スキル

左の一覧からスキルを1つ選び、右で名前と説明を編集します。スキル名は1行、説明は複数行です。保護中のスキルは確認操作なしに置き換えません。

「デフォルトスキルを選択…」では、同梱カタログからゲーム内デフォルトスキルを選べます。選択直後は未確定なので名前と説明を編集できます。そのまま保存した場合だけ正規デフォルトとして内部ID・種別・キーを確定し、名前または説明を変更して保存した場合はオリジナルスキルとして保存します。

性格キーワード

設定枠を選び、名前の部分一致または分類からキーワードを探します。カタログにない文字列を自由入力する機能ではありません。

思い出

思い出の追加、順序変更、空白保持枠への置換を行えます。文章項目は複数行を使えます。

AI向けMarkdown形式 v2

AIへ内容を渡す中間形式の番号は「AI向けMarkdown形式 v2」です。アプリケーションバージョン 2.1.0とは別の番号です。

Markdownを書き出す

開いているシートの基本項目、ステータス、性格キーワード、スキル、AI参照用の思い出を書き出します。画像と内部IDは含みません。

Markdownから新規作成

形式を検査し、詳細プレビューで内容を確認した後、新しいシートを作ります。現在開いているHTMLを直接書き換えません。

重要: 思い出は件数と構造を検出しますが、Markdownから新規作成したシートへは復元されません。画像と内部IDも復元されず、スキルは新しいオリジナルスキルになります。

旧形式Markdown

マーカーなしを含む旧形式を検出した場合、内容を先に解析しません。「旧形式として解析する」を明示した後にだけ詳細プレビューへ進みます。欠落項目は警告になり、解釈が一意でない構造や未知のH2/H3見出しはエラーになります。

読み取り専用とエラー

HTML内の表示とデータが安全に対応付けられないときは、推測して保存せず、内容を読み取り専用で表示します。

  • 元のゲームからHTMLをもう一度出力して試します。
  • エラー画面の「原因」「影響」「対処」を確認します。
  • 元ファイルを手作業で直す前に、別の場所へコピーを残します。

別名で保存する

  1. 画面下のエラーがなく、変更件数が意図どおりか確認します。
  2. 「別名で保存」を押します。
  3. 元HTMLとは別のファイル名を選びます。
  4. 保存完了表示を確認します。

大切なシートは、ゲームで読み込めることを確認するまで元HTMLを残してください。

安全上の注意

Windows SmartScreenが表示された場合

配布元とファイル名が案内どおりか確認してください。不明な入手元の実行ファイルは開かないでください。このガイドは個人端末のSmartScreen実画面を掲載せず、文章で説明しています。

確認の流れ: 配布元を確認 → ウイルス対策ソフトで検査 → 信頼できる配布物だけを起動。 判断できない場合は中止してください。

AIへ渡す前に

Markdownにはプロフィールや思い出の文章が含まれます。個人情報や共有したくない設定がないか、テキストエディターで確認してください。

困ったとき

保存ボタンを押せません

読み取り専用、入力エラー、スキル置換の未確認がないか、画面下の状態表示を確認してください。

プロフィールの改行が消えました

アプリケーションバージョン 2.1.0では、プロフィールHTMLの <br> を意味のある改行として扱います。古い実行ファイルを起動していないか確認してください。

Markdownで編集した思い出が戻りません

仕様です。AI向けMarkdown形式 v2の思い出はAI参照用で、Markdownから新規作成しても復元されません。

画面が見づらいです

メニューの「表示」→「外観」から、ライト、ダーク、ハイコントラストを選べます。
